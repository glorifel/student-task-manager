# Student Task Manager

A simple school project website using PHP, MySQL, HTML, and CSS.

## Features
- Add a school task
- Set a due date
- Choose Low, Medium, or High priority
- Mark tasks as completed
- Undo completion
- Delete tasks
- Store tasks in a MySQL database

## Database setup
1. Create a MySQL database named `student_tasks`.
2. Import `database.sql`.
3. Check the MySQL username/password in `db.php`.
4. Put the project in a PHP server such as XAMPP.
5. Open `index.php` in the browser.

## Files
- `index.php` - main page
- `db.php` - database connection
- `add_task.php` - adds tasks
- `update_task.php` - changes task status
- `delete_task.php` - deletes tasks
- `database.sql` - database/table setup
- `style.css` - website design
